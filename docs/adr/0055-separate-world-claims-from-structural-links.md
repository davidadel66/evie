# Separate world Claims from structural Graph Links

Claims represent temporal propositions about the world from an Entity to another
Entity or Typed Literal. Graph Links use a closed relation set only for structural
relationships among memory records, such as contradiction, generalization, and
derivation; generic Entity relationships remain Claims. Source authority is
preserved as provenance and may inform later evaluated proposals or ranking, but
Stage 3 never silently chooses a winning Claim when accepted evidence conflicts.
Conflicting accepted Claims coexist with their sources; an explicit structural
Link may record a recognized contradiction without changing either lifecycle.
