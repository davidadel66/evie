# Evaluate memory as separate systems

Evie evaluates accepted semantic state, learned extraction, retrieval, and
end-to-end answers separately so one aggregate score cannot hide a deterministic
safety or provenance failure. Stage 3 establishes versioned model-free fixtures,
exact conformance gates, and reproducible performance baselines by applying
human-authored typed operations to synthetic evidence. Stage 4 separately grades
model-extracted candidates against human-reviewed gold expectations, Stage 5
adds retrieval metrics, and Stage 9 adds pinned external benchmarks and redacted
end-to-end replays.
