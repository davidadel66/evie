# Separate semantic state, extraction, and retrieval

Stage 3 establishes only the deterministic Semantic Memory domain: entities,
Claims, source links, accepted Semantic Operations, lifecycle transitions,
scope revisions, exact temporal and provenance queries, and replay. Model
extraction, candidates, fuzzy identity resolution, and compiler jobs belong to
Stage 4; FTS generations, embeddings, relevance ranking, and request-context
injection belong to Stage 5. Stage 3 admits changes only through explicit
accepted operations so model judgment cannot obscure whether the underlying
semantic rules are correct.
