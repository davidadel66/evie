# Add Workspaces for ongoing life and business areas

Evie will add Workspace as a durable scope alongside global, filesystem
project, and session scopes. A Workspace such as Cairo's Kitchen groups its
memory, approved workflows, allowed Connection IDs, business configuration,
and default Agent Preset. Reusable behavior remains in plugins, while the
Workspace represents the owner's actual operating context and data. The memory
spec must add this scope explicitly rather than placing business knowledge in
global memory or a synthetic code project.
