# Allow scoped recall across conversations

Stage 5 may search eligible excerpts from earlier conversations in the same
Workspace or project, or earlier Global conversations from a Global session,
so original evidence remains recoverable when semantic extraction did not
retain it. This narrowly replaces the blanket other-session exclusion for
conversation evidence: another session's session-scoped Claims and unrelated
areas remain excluded, access to accepted Global memories does not grant raw
Global-history access from a Workspace or project, and reading evidence does
not accept or promote a Claim. No private-conversation setting is introduced;
existing source eligibility and remote-egress rules still apply, preserving
area isolation while allowing continuity across conversations within an area.
