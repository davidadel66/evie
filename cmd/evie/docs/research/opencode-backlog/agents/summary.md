# A07 - Summary agent

Status: parked, unapproved. Kind: hidden internal profile in OpenCode.

## Purpose

Produce concise release/PR-style prose from completed work.

## How OpenCode does it

OpenCode registers a hidden, tool-free `summary` profile whose prompt asks for a
two-to-three-sentence pull-request description. At the inspected revision, no
shipped runtime selector for this profile was found. OpenCode's similarly named
`SessionSummary` service computes file diffs and session change metadata; that
is a different mechanism.

## EVIE assessment

Do not copy a dormant profile just to match OpenCode. EVIE already needs two
more precise artifacts:

- a deterministic build report containing exact gates and outcomes; and
- a final user response generated by the owning build agent.

A summary profile becomes useful only if EVIE later creates commits, pull
requests, release notes, or sanitized session exports.

## Proposed constraints if promoted

- Tool-free.
- Input is an explicit diff/build report, not the unrestricted transcript.
- Never claim checks that are absent from evidence.
- Preserve known gaps and skipped verification.
- Human approval before publishing prose externally.

## Acceptance evidence

- Every factual completion claim is traceable to the supplied report.
- The profile cannot inspect secrets or invoke tools.
- Empty/no-change sessions do not produce invented accomplishments.
