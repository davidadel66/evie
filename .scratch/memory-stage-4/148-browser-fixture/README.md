# Compiler diagnostics browser fixture

Disposable real SQLite and real HTTP/React UI, with scripted extraction and an actual closed loopback endpoint. The fixture creates a failed earlier generation, later candidate success, retryable endpoint failure, an explicit two-event historical selection, an activation and an unfinished turn held live during reconciliation, plus outside-selection retained events. Source sessions are closed before browsing. No real provider, owner review or model quality is claimed.

Root copies the two Go files into the exact isolated ticket snapshot, builds the demo binary there, and runs `node .scratch/memory-stage-4/browser-driver/check-148.cjs` from the repository root. The driver reads 148-checkpoint.json, launches installed Chrome headlessly in a fresh profile, and uses the actual UI and HTTP. It replaces bounded pages, handles empty candidate continuation pages, and verifies a delayed real response cannot restore a previous view. Finalization observations remain absent because this fixture writes source events directly rather than running a foreground agent response.

The binary deletes its temporary database on SIGINT; the driver closes Chrome, waits for clean server shutdown, and records cleanup, source tree, driver hash, exact requests, screenshots and browser errors. No source text, model prompt or endpoint is rendered in diagnostics. The initial accepted-memory tab is not wired in this review-only fixture, so its context-scope request receives an expected 405; compiler routes are fully wired and return 200. Accepted-state browser/replay is the separate conformance story.

Preserved harness attempts: initial exact label matching was too strict for a label wrapping a select; the fixture originally released the turn lease before reconciliation, making the abandoned prefix legitimately queued; initial assertions incorrectly assumed the first bounded candidate page was nonempty; the delay harness initially removed its route before fulfillment completed. These were harness fixes, not production changes.
