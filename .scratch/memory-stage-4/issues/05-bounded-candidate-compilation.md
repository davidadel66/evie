## Acceptance criteria

- [ ] From committed eligible Episodic Memory, select one bounded source unit under a pinned Compiler Generation and produce a durable candidate group or a recorded successful zero-candidate completion.
- [ ] The same narrow path runs against the selected local runtime and against a scripted extractor for deterministic tests. Enforce configured loopback/Unix transport, no redirects/nonlocal endpoints/fallback, input/output limits, cancellation, and bounded structured-output validation.
- [ ] The Kernel binds destination scope, computes and validates exact projected evidence and hashes, and distinguishes supporting evidence from interpretation context. Malicious output cannot grant scope, source authority, or accepted effects.
- [ ] CLI inspection shows candidate meaning, exact support, original authority, scope, generation, and review state through the shared Kernel seam. Source projection agrees with the frozen contract; no full-event fallback exposes unrelated content.
- [ ] Apply secret exclusion and prohibited-source rules before extraction and validation. Missing/invalid sources, invalid structure, and missing model output are failures, not successful empty results.
- [ ] Persist candidate group, completion, and exact coverage atomically according to the contract. Repeated scheduling/delivery and reopen preserve one logical outcome; enforce a durable cross-process request guard and fencing from the first extraction path.
- [ ] Candidates remain absent from accepted queries, traversal, and replay. Generic SQL/file tools cannot access newly introduced memory-owned storage, and unavailable/unconfigured extraction does not disable explicit Semantic Memory.
- [ ] Exercise real-SQLite Kernel tests, source/Unicode/scope boundary cases, local HTTP transport fixtures, reopen/idempotency, and CLI inspection. Run repository-required full change verification.
- [ ] Defer ongoing scheduling, automatic recovery, broad candidate types, and owner acceptance to their dependent slices; demonstrate this bounded path independently.
