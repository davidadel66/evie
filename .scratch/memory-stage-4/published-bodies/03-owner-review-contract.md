## Parent

[Memory Stage 4: Compile sourced memory candidates for owner review](https://github.com/davidadel66/evie/issues/131)

## What to build

Resolve the owner-review prerequisite as a typed Kernel authority contract. Demonstrate review of an inactive source session without reopening it or weakening the existing session-bound explicit-memory commands. Define review outcomes and transactions before implementing acceptance or its adapters.

## Acceptance criteria

- [ ] Define which authenticated owner context may list, inspect, and review a candidate in each applicable scope after its source conversation closes. Preserve visibility and explicit Promotion rules.
- [ ] Specify the immutable effect/preview identity and revision binding, source eligibility revalidation, identity and conflict checks, stale-preview response, and when refreshed owner approval is required.
- [ ] Define accept, reject, repeated delivery, already-resolved candidates, and owner edits. Preserve original extraction, evidence, and review lineage rather than overwriting the proposal.
- [ ] Keep original source authority separate from approval authority. Accepting a tool observation cannot turn it into an owner assertion; model confidence cannot supply authorization.
- [ ] Define dependent resolution and Predicate additions, temporal/correction effects, atomic groups, independent batch-item failure behavior, batch bounds, and exact source/effect disclosure.
- [ ] Specify atomic candidate resolution/audit and Semantic Operation effects, concurrency with graph changes and competing reviews, rollback behavior, and model-independent replay.
- [ ] Provide worked examples for an inactive session, stale revisions, changed source eligibility, an edited interpretation, rejection, and a partly failing dependent batch. These become the acceptance oracles for the CLI and web.
- [ ] Record material owner decisions and boundary risks in the binding record; run documentation whitespace/local-link checks. Leave exact adapter commands/routes to their implementation tickets.
