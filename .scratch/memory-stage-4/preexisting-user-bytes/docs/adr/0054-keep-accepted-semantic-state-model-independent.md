# Keep accepted semantic state model-independent

Accepted Entities and Claims contain stable semantic identity, typed proposition,
scope, time, lifecycle, and provenance, but no extractor confidence, prompt/model
version, or model-derived Entity summary. Stage 4 Candidates own learned scores
and extractor configuration; an accepted Semantic Operation may retain the
originating Candidate ID for audit without making Candidate metadata part of
truth or replay. Human-authored descriptions remain ordinary Claims, while
generated summaries are later disposable projections.
