# Preserve semantic history through lifecycle changes

Retirement, source retraction, and session closure never delete accepted
Semantic Memory. Entity retirement may affect dependent Aliases, Claims, and
Graph Links only through an explicitly enumerated atomic proposal, never a hidden
cascade. A Claim with no eligible active source becomes unsupported and leaves
normal current retrieval without changing its historical lifecycle; restoring an
eligible source may make it current again. Archived session memory remains
available only to replay, explicit inspection, or the same resumed session until
an approved promotion creates broader-scoped memory.
