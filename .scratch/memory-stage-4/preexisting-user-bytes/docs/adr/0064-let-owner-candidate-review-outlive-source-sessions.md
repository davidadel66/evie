# Let owner candidate review outlive source sessions

Stage 4 provides scope-level owner review of Memory Candidates after their
originating conversations close, without requiring those conversations to be
revived. Exact source evidence and its original authority remain distinct from
the owner's approval of a proposed effect, so asynchronous review neither
strands old suggestions nor turns assistant or tool evidence into an owner
assertion; Stage 3's session-bound explicit operations remain unchanged.
