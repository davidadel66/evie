# Require explicit approval for model-structured semantic changes

In Stage 3, the conversational model may translate an explicit owner request
into a typed Memory Operation Proposal, but the proposal must display its exact
scope, proposition, evidence, and temporal effect and receive approval before it
becomes an accepted Semantic Operation. Corrections distinguish prior error from
a real-world change at an effective Valid Time. Retirement and restoration are
reversible accepted operations; Hard Erasure remains a separate feature because
it must coordinate retained evidence and every derived representation. Approval
also binds the proposal's exact revision vector; a stale proposal is shown again
against current state rather than silently rebased into a different operation.
Stage 3 adds no semantic proposal table: session-bound proposals and decisions
remain episodic audit events, while only accepted operations enter semantic
history. Durable Candidate review belongs to Stage 4.
